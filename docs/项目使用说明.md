# 项目使用说明（非技术同事版）

## 这个项目做什么

它把翱象和淘宝闪购后台的数据整理到同一个 MySQL 数据库，再把看板需要的数据生成成 JSON 文件，供网页展示。你在网页上看到的日期，最终都应该来自同一条数据链路。

## 想做什么，去哪里找

| 你的目标 | 对应位置 | 是否建议自己改 |
| --- | --- | --- |
| 看网页、调整文案、颜色、页面布局 | `web/src/` | 小改可以；改前先备份或让开发协助 |
| 看板已经生成好的数据 | `web/src/data/` | 不建议手改；下次刷新会被覆盖 |
| 每日抓数据、导入数据库 | `automation/scripts/` | 不建议直接改，先确认口径 |
| 查看每次抓取的原始 Excel 和运行日志 | `automation/output/` | 可查看、可用于对账；不提交 Git |
| 数据库表结构 | `database/mysql-schema.sql` | 仅开发人员改；改前先备份数据库 |
| 本机数据接口 | `server/mysql-api.mjs` | 通常不用改 |
| 人工上传页面的 Excel 模板 | `assets/templates/` | 可以下载、填写；页面上传目前只在浏览器预览 |
| 历史原型、旧代码、旧测试资料 | `archive/` | 只作追溯，不用于日常运行 |

## 每日数据如何更新

```text
后台导出数据
  ↓
automation/scripts/daily-run.ps1 采集、校验、入库
  ↓
MySQL 的 dashboard 数据库
  ↓
sync-db-to-json.mjs 生成 web/src/data 中的 JSON
  ↓
重新构建 / 发布网页
```

这里有一个重要原则：**不要为了让页面变动而直接改 JSON。** 应先确认数据库是否已经有最新数据；JSON 是数据库的网页副本，不是主数据。

## 页面代码怎么找

- 页面和组件：`web/src/components/`。文件名通常能看出页面主题，例如 `Traffic`、`Profit`、`Risk`。
- 全局入口与路由：`web/src/App.vue`、`web/src/main.ts`。
- 样式：组件旁边的 `<style>`，以及 `web/src/styles/`。
- 前端数据：`web/src/data/*.json`，由程序自动生成。

如果只是改一个中文标题，先在 `web/src/` 中全文搜索这句文字；如果是某个数字或日期不对，先查 `automation/output/` 和 MySQL 水位，而不是在页面中找。

## 发布前最小检查

1. 确认 VPN 已连接、当日抓取没有报错。
2. 确认 MySQL 的 `refresh_state` 日期与对应事实表一致。
3. 运行 `npm --prefix web run build`；构建成功才发布。
4. 打开网页核对关键页面的“数据截至日期”。

## 不要碰的内容

- `automation/.env`：里面是本机连接配置，绝不上传或发到群里。
- `node_modules/`：依赖缓存，删了可以重新安装，不是项目代码。
- `archive/`：历史资料，不要从这里复制脚本回当前链路。

技术边界说明见 [架构与运行边界](架构与运行边界.md)。
