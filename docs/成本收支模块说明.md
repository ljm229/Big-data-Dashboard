## 数据来源与口径

实际读取 `数据源1/翱象/渠道门店周期数据近30日.xlsx` 的 `data` 表及门店城市目录。当前导入 1,009 条有效门店渠道日记录，2026-08-15 至 2026-09-13；707 条全空指标记录不作为有效收支数据。每条记录保存源行号；快照记录文件 SHA-256、工作表、列位置与导入时间。截图仅为布局参考，不把截图金额写成数据。

| 展示指标 | 计算 / 来源列 |
| --- | --- |
| 经营收入 | 总营业额 AB − 营销活动费用 CJ |
| 成本支出 | 商品成本 CP + 平台配送 CS + 佣金及其他平台费用 CM + 自配送 CV + 推广 DK + 订单线下维护 AN |
| 收支结余 | 经营收入 − 成本支出，不含平台后返 |
| 收支结余（含后返） | 收支结余 + 平台后返 DN |
| 收入组成 | 商品原价 AE、包装费 AH、应收配送费与地址变更费 AK（合并列） |
| 原始参考 | 预计线上收入 D、预计线上支出 CA、预计毛利 P、含后返毛利 G、平台补贴 DE |

当前有效记录中，D = AB − CA；CA = CJ + CM + CS。因此 D、CA 不能直接当作参考截图中的总收入、总支出。以上是当前导出数据的核对结果，不宣称是所有平台、所有版本的会计定义。

源表毛利通常为 D − CP − CV − AN，未扣推广；本模块扣推广并将后返单列，所以不能与大屏顶部含后返毛利混用。发现源行 1091（2026-08-27）毛利有 23.56 元差异，保持原值，在对应筛选范围的「数据来源与口径核对」中披露，不把差异塞入“其他成本”强行补平。

当前没有房租、人工、水电及完整线下账本，此处结余不是财务净利润；也不是到账现金。未提供的销售开单收入、其他收入、公益捐款等不补零。平台补贴保留原值参考，不额外加进收入。

### 缺失与比较

- 空值不是零：明细可显示已知小计及有效记录覆盖；合成指标任一必要字段缺失，合成值显示 `—`。
- 商品原价/应收配送部分零订单记录为空，但营业额为源表明确值；经营收入以明确的营业额计算，不能把空明细伪装为零。
- 费用有负调整、合计为零或不完整时停用占比环图，保留原始金额。
- 只比较等长、逐日偏移下门店渠道记录覆盖一致的两期。零/负基期、缺失值及不完整月无可用环比时显示 `—`，不拿最近一日替代。
- 无当前数据时为空态，不回退旧日、不填 0；门店数是有数据的门店，不等于已营业门店数。
