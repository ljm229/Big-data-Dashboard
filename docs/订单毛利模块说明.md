# 订单毛利（全量订单）

## 数据

- 源文件：`数据源1/翱象/订单毛利导出*.xlsx`（忽略 `~$` 临时锁文件；取最新）
- 快照：`web/src/data/orderMarginData.json`
- 导入：`npm run data:sync-order-margin`

## 口径

- 导出含**全量订单**（正/负毛利均计入分母）。
- **负贡献订单率** = 预计毛利 &lt; 0 的订单数 / 全量订单数。
- **＞3 元负毛利占比** = 预计毛利 ≤ −3 元订单数 / 全量订单数。
- 负毛利原因归类：商品毛利、营销折扣、配送、平台费用四项中拖累最大（最负）的一项。
- 影响金额 = 负毛利订单预计毛利合计（绝对值展示）。

## 展示约定

- 百分比一律 `%`，不用 `pct`。
- 日对比写「日比」，周对比写「周比」，月对比写「月比」；不用「较上期 / 日环比 / 周环比」。

## 界面

挂在「利润成本」：

- **风险异常表**（原「本期利润对比」位）：下列负毛利占比 &gt; 0 的门店明细（负毛利占比 / ＞3 元占比，周比合并展示）；默认按负毛利占比降序；支持表头排序与店名搜索
- **效能排行表**（原「亏损排行」位）：只列反后日均毛利 &gt; 0 的门店；字段为日均订单 / 反后日均毛利（周比合并展示）；默认按反后日均毛利降序
- 负贡献订单结构、利润漏损 TOP5
