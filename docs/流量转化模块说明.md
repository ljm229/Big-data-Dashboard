# 流量转化 · 按日分来源明细

更新时间：2026-09-15。沿用项目现有 Vue / Pinia 与浅色经典看板设计。

## 入口和布局

经典看板 → 流量转化；也可访问 `http://127.0.0.1:5173/?view=ops&edition=classic&tab=traffic`。

- 顶栏日期可切片；视角切换「平台渠道 / APP 内页面」（互斥）。
- 第一排：曝光、进店、下单、P1、P2、整体；各带日比 / 周比。
- 第二排：转化漏斗、按日趋势（当前筛选 / 近7日 / 近30日）、来源结构。
- 第三排：来源转化效果、城市 / 门店榜（含整体周比）、异常 TOP（第二步，暂空态）。

## 当前来源

`数据源1/淘宝闪购商家/流量分析-分来源数据下载_8.15-9.13.xlsx`

- `data`：4,437 条按日记录，30 天（2026-08-15～09-13），18 店 / 8 城。
- 日期格式 `YYYYMMDD`；`grain=day`。
- `meta` 导出时间以文件为准；界面标注非实时。
- 无覆盖的城市 / 门店 / 日期显示空态，不回退 opsPack，不补样例。

## 计算边界

1. 「分平台渠道」与「淘宝闪购APP内渠道」绝不相加。
2. 人数为记录加总，不声称为跨来源 / 跨门店去重 UV。
3. 单条记录转化率取 Excel 原值；多条为 Σ分子 / Σ分母。
4. 日比 = 同跨度上一段；周比 = 整体平移 7 天。人数用相对变化，转化率用百分点差，展示统一用 `%`。
5. 趋势只做按日序列；缺日不补 0。无小时字段，不伪造小时曲线。
6. 异常 TOP 规则第二步再接。
