# 核心指标追踪模块说明

## 定位

「城市 / 门店经营 → **核心指标追踪**」回答 3km 竞争位置：净 G 排名、主搜渗透率、距 Top1 的日均缺口。**不是** source1 日切经营数据，页顶会标明数据日期与手工同步方式。

## 数据源

- Excel：`数据源1/翱象/门店核心指标追踪表.xlsx`（或目录内同名最新文件）
- 表头在第 3 行，数据从第 4 行起
- 同步命令（在 `web` 目录）：

```bash
npm run data:sync-compete
# 可选指定业务日期
node ../scripts/sync-compete-track.mjs --date=2026-09-18
```

产物：`web/src/data/storeCompeteTrack.json`

## 字段与计算

| 逻辑字段 | Excel 列名（示例） |
|----------|-------------------|
| storeName | 店名 |
| mtdNetGRank3km | mtd净G排名_3km |
| mtdSearchPenetration | mtd主搜渗透率 |
| mtdSearchRank3km | 主搜渗透排名_3km |
| currentDailyNetG | 当前日均净G |
| top1RequiredDailyNetG | 达到top1本月剩余天需达成日均净G |
| competitorSearchPenetration | 竞对门店主搜渗透率 |

脚本计算：

- `top1DailyGap = top1RequiredDailyNetG - currentDailyNetG`
- `searchGapPp = mtdSearchPenetration - competitorSearchPenetration`（百分点，渗透率已归一化为 0–100）

城市缺列时从 `source1.json` 门店清单补全。

## 与全局筛选

- **数据日期**：仅来自 JSON `meta.dataDate`，**不**跟随大屏/source1 的 `selectedDate`
- **城市 / 门店**：与看板顶栏筛选联动

## 状态规则

状态（Top1 / 接近Top1 / 重点冲刺 / 差距较大）阈值在 `web/src/utils/competeTrack.ts` 的 `STATUS_CONFIG`，**待业务确认**后调整。
