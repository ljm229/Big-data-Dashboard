# 管理层大屏开发与数据边界说明

## 本版范围

管理层版已实现「城市门店」「利润成本」「渠道订单」「商品品类」「流量转化」「门店运营质量」和「预警中心」七个入口，默认进入「城市门店」。

## 展示原则

- 数值优先直接使用已接入数据；可加总指标只做同口径汇总。
- 比率按「分子合计 ÷ 分母合计」计算，不对百分比做算术平均。
- 无分母、无归因或无明细字段时展示「—」或空状态，不补齐、不猜测。
- 不使用未经确认的金额阈值、退款金额推算、店铺经纬度或风险规则。
- 流量数据为 2026-08-15 至 2026-09-13 按日分来源明细，可按顶栏日期切片；趋势为按日曲线，无小时字段不伪造小时曲线。

## 各页数据边界

| 页面 | 已展示 | 保留空态的内容 |
| --- | --- | --- |
| 城市门店 | 城市经营地图、城市贡献排行、重点门店、经营矩阵、门店结构、上线进度 | 风险分布、问题行动台账、门店精确经纬度 |
| 利润成本 | 收入到贡献利润漏布、上期对比、成本费用构成、对象排名 | 负贡献订单拆分、目标缺口、约定的高风险阈值 |
| 渠道订单 | 渠道贡献、订单量、利润率、单均利润、城市渠道矩阵 | 小时趋势、订单生命周期、履约异常、退款金额 |
| 商品品类 | 品类销售、缺货影响门店、缺货损失、库存品项排名 | 品类利润、负利品类、周转天数、核心商品可售率、库存日趋势 |
| 流量转化 | 曝光、进店、下单、P1/P2/整体、日比/周比、漏斗、按日趋势、来源结构、城市/门店榜 | 小时趋势、异常 TOP（第二步）、投放成本/ROI |
| 门店运营质量 | 综合合格率、D 红线店、指标热力矩阵、门店详情、问题门店排名、指标趋势和整改建议 | 责任人、截止日期、真实整改状态和逾期数需待闭环台账接入 |
| 预警中心 | 管理层原型结构和空状态 | 预警事件、规则命中、责任人、处置时限与闭环状态 |

## 交互与适配

- 城市、门店与页面内图表可联动筛选。
- 标签页支持桌面大屏与 390px 窄屏；窄屏导航保持可见并允许横向滑动。
- 选中页面有 `aria-current` 标识；图表表格在窄屏内部滚动，不撑宽整页。

## 管理层版视觉规范

视觉方向继承 `原型设计/管理层版-v2` 中的 01–06 号原型，不改变业务结构与取数口径。

- **记忆点**：顶栏采用「左侧导航—居中驾驶舱标题—右侧筛选和数据日期」，标题两侧使用细线科技翼展示驾驶舱属性。
- **主色**：链接/图表强调 `#3B82F6`；选中按钮深灰 `#111827`；页面底 `#F3F4F6`，卡片 `#F9FAFB`；KPI 主值深字 `#111827`。绿/红只用于正负状态。
- **字体**：中文优先 `Microsoft YaHei UI / PingFang SC`；数字优先 `Bahnschrift / DIN Alternate`，并启用等宽数字以便排行对齐。
- **字号层级**：页面主标题 23px，卡片标题 18px，KPI 数字 34px，正文 12–13px。
- **卡片**：8px 圆角、蓝灰细边框和轻阴影；KPI 使用浅蓝圆形图标、大号深蓝数字与弱化的辅助说明。
- **栅格**：1920px 尽量填满首屏；1280px 顶栏自动拆成两行；390px 指标卡双列并保留可滑动导航。
