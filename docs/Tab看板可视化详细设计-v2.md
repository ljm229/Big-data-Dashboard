# Tab 看板可视化详细设计 v2

## 1. 设计目标

看板服务两类人：老板判断整体经营是否健康，主管定位负责门店的问题并安排当天动作。页面统一采用“结论区 → 核心图 → 诊断图 → 行动区”的阅读顺序。明细表不放在首屏，后续作为图表点击后的抽屉明细或下载入口。

保留“门店运营质量”现有内容和评分逻辑，其余 Tab 根据数据源重做。

## 2. 页面与角色

### 老板视角

- 默认全部城市、全部门店。
- 首先展示整体规模、变化、结构和风险集中度。
- 重点回答：结果是否达标、问题集中在哪个环节、哪些区域或门店影响最大。
- 图表优先使用贡献图、趋势图、象限图和 Pareto 图。

### 主管视角

- 通过城市和门店筛选查看管辖范围。
- 首先展示异常门店、异常商品、异常来源和建议动作。
- 重点回答：今天先处理哪家店、检查什么、改善后看哪个指标。
- 后续接入主管—门店映射后，默认筛选到该主管的门店集合。

## 3. 视觉系统

| 用途 | 色值 | 使用位置 |
|---|---|---|
| 主色 | `#1D6BFF` | 经营规模、主趋势、正常流量 |
| 机会蓝 | `#0EA5E9` | 漏斗中段、辅助信息 |
| 健康绿 | `#14B8A6` | 达标、及时、健康象限 |
| 预警橙 | `#F59E0B` | 待关注、缺货、投入偏弱 |
| 风险红 | `#EF5B5B` | 未达标、退款、履约不及时 |
| 活动紫 | `#8B5CF6` | 推广费、活动、新客 |
| 标题文字 | `#0F172A` | 标题与关键数字 |
| 次要文字 | `#64748B` | 解释、坐标、注释 |
| 页面底色 | `#F4F7FB` | 看板背景 |
| 分隔线 | `#E8EEF6` | 卡片边界与网格线 |

规则：同一语义全站保持同色；红色只表示需要处理的风险；一个图最多保留 6 个主色，更多类目用同色明度变化；装饰渐变只用于标题带，数据图形使用纯色，避免误导数值大小。

## 4. Tab 结构与图表

### 01 门店运营质量（保留）

数据：门店营运考核指标。

- 保留五项质量指标、达标线、门店排行和辅导标签。
- 老板看达标率和不达标门店分布；主管看负责门店的未达标项。
- 与其它 Tab 的联动入口：履约异常跳到“逆向客诉”，商品出勤问题跳到“商品供给”。

### 02 经营结果

数据：经营趋势、渠道周期趋势、渠道门店周期趋势。

1. 经营概览：订单、实付、客单、毛利、毛利率、退款率等关键数，只保留一条紧凑指标带。
2. 渠道实付贡献：横向条形图，长度表示实付金额，尾端标注金额与份额；渠道颜色固定。
3. 每日订单趋势：订单折线叠加实付柱，识别规模变化来自单量还是金额。
4. 经营判断：系统生成一句结论，并提示下钻顺序。
5. 门店规模 Top10：横向条形图。
6. 门店增长榜：正负条形图，绿色增长、红色下降。

不在首屏展示“门店 × 渠道”大表。明细通过点击门店或下载获取。

### 03 流量与转化

数据：流量分析—分来源数据，30 日、18 家门店。

1. 三级漏斗：曝光人数 → 进店人数 → 下单人数；阶段之间直接标 P1、P2 和流失人数。
2. 断点结论：P1 低于 8% 判为入口问题，P2 低于 22% 判为商品、价格或活动承接问题。
3. 来源规模与效率：横向条形图按曝光排序，颜色表示整体转化是否健康。
4. 门店 P1 × P2 象限：横轴 P1、纵轴 P2、气泡大小为下单人数；虚线标健康线。
5. 今天先处理：列出最多 4 家异常店及检查动作。

### 04 推广与活动

数据：经营趋势中的推广费用、活动成本；活动分析中的活动成交、商补、订单、新老客。

1. 投入与成交趋势：推广费、活动成本用堆叠柱，全店实付用折线。
2. 活动投入产出象限：横轴商家补贴，纵轴活动成交，气泡大小为新客数；右上象限用于识别可放大的活动。
3. 拉新结构：新客与老客使用环形饼图，直接标人数、占比；同时显示当前周期有活动记录的门店覆盖数，并列出成交规模最大的活动。
4. 口径提示：“全店实付 / 推广费”用于观察投入强度，不命名为广告 ROAS，避免把全店自然成交错误归因给推广。

当前数据不能支持“预算执行率”和“小时出价效果”，因此不展示空卡片。待下载预算、推广消耗小时明细后再增加时段热力图和预算仪表。

### 05 商品供给

数据：商品分析明细中的销售额、销量、退款、缺货次数及预计损失；供给汇总存在时补充出勤率。

1. 品类成交版图：矩形树图，面积表示销售额，颜色表示一级类目。
2. 缺货损失 SKU Top：横向条形图，按预计损失金额排序；次数只用于提示，不替代金额优先级。
3. 门店供给风险：横轴销售额，纵轴缺货预计损失 / 销售额，气泡大小为缺货次数。
4. 补货优先级：列出高损失商品，供主管直接安排补货。

商品明细为 2026-08-13～2026-09-11 下载区间汇总，当前不能随日筛选精确切片，页面明确标示区间口径。

### 06 逆向客诉

数据：逆向订单明细、配送异常订单明细。

1. 原因 Pareto：原因量柱形图叠加累计占比折线，优先解决覆盖大多数逆向的前几项原因。
2. 逆向类型结构：环图展示全部取消、部分取消、全部退款、部分退款等构成。
3. 配送履约趋势：100% 堆叠柱展示及时、不及时、缺少节点三类比例变化。
4. 门店风险象限：横轴逆向订单数，纵轴配送不及时率，气泡大小代表风险规模。
5. 重点客诉商品：按逆向商品行数排序，辅助定位商品问题。

逆向订单按订单 ID 去重；原因、类目和商品次数按退货商品行统计。两种分母不能混用。

### 07 门店辅导

数据：前六个 Tab 的异常结果，后续叠加辅导任务状态。

- 看板式三列：待处理、处理中、已复盘。
- 每张任务只保留门店、问题标签、建议动作、负责人、截止时间和复盘指标。
- 老板看问题分布与完成率；主管看当天任务清单。

## 5. 数据下载设计

下载按“时间、组织、对象、指标”四类字段组织。默认导出当前筛选结果，并在文件首行写入口径和生成时间。

| 下载主题 | 必选维度 | 可选维度 | 指标 |
|---|---|---|---|
| 经营结果 | 日期、城市、门店、渠道 | 主管 | 订单、实付、客单、收入、支出、毛利、毛利率、退款率 |
| 流量转化 | 日期、城市、门店、来源分类、来源名称 | 主管 | 曝光、进店、下单人数、P1、P2、整体转化 |
| 推广活动 | 日期、门店、活动 ID、活动名称、活动类型 | 活动来源、状态 | 推广费、活动成本、商补、活动成交、活动订单、新老客 |
| 商品供给 | 下载区间、门店、商品 ID、商品、一级/二级/三级类目 | 商品条码 | 销售额、销量、带来订单、退款额、退款单、缺货次数、预计损失 |
| 逆向客诉 | 日期、城市、门店、订单 ID、逆向类型、原因 | 商品、类目 | 成交金额、退货金额、逆向商品行数 |
| 配送异常 | 日期、城市、门店、订单 ID、配送状态 | 商责/骑手判定 | 及时、不及时、缺少节点、拣货完成和送达时间 |
| 门店辅导 | 周期、主管、城市、门店、问题标签 | 任务状态 | 基线值、目标值、复盘值、完成时间 |

### 下载交互

- 每个 Tab 右上角提供“下载当前数据”。
- 点击图形元素后，下载范围自动缩小到该来源、门店、商品或原因。
- 老板默认下载汇总数据；主管默认下载门店明细。
- 大明细异步生成，下载历史显示筛选条件、口径、文件大小和有效期。

## 6. 指标口径保护

- 周口径固定为周五至次周周四；周环比对照紧邻的上一周同口径数据。
- 比率一律用分子合计 / 分母合计重算，不平均门店百分比。
- 金额统一保留两位小数，页面可缩写为万，下载保留原值。
- 商品区间表不能伪装成日数据。
- 无分母不计算占比；无归因数据不命名为 ROAS。
- “配送不及时率”分母为及时 + 不及时 + 缺少节点；如业务要排除缺少节点，需要另建口径并命名。
- 数据更新时间、覆盖日期、门店数始终显示在页头数据源标签或下载说明中。
