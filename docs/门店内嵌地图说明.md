# 门店内嵌地图

更新：2026-09-15。范围仅为经营总览的门店地图，未改动 Excel 原文件、数据库、采集程序及其他看板模块。

## 使用

- 仅选择城市（顶部筛选或底部城市快捷按钮）时，保持全国图并弹出城市经营摘要，不自动进入门店位置。即使之前处于门店地图，也先回到城市摘要。
- 选择具体门店，或点击城市摘要里的“查看门店明细”，才进入门店地图。把具体门店切回“全部门店”时，恢复该城市摘要。
- “街道地图”在原地图区域加载道路底图，无需高德账号、API Key 或跳转外部网站。
- “区域分布”保留大屏原有蓝色行政区域图，可离线使用已打包的底图。
- 点地图标记或底部门店名称，在同一块区域查看地址、经营指标并聚焦当前概位。右侧详情与地图分栏，不盖住点位。
- “查看全城门店”重新适配全部点位。“只看该店”会应用全局门店筛选，但地图仍保留同城全部门店作为位置参照。
- 支持缩放、拖动、全屏、返回全国；14 个城市、32 家门店（包括待上线门店）可通过城市与门店选择器访问。

## 定位精度边界

当前 Excel 提供地址，但没有经过核验的经纬度。项目既有坐标全部是硬编码的地址概位，不能作为精确门牌、配送距离或导航依据。街道底图不会自动使这些坐标变准确，也不表示已经对 32 家门店完成地理编码。

界面因此持续显示“位置待核验”，待上线或无经营指标的门店不标成“正常”。未知门店回退到明确标注的城市中心，不再人为散开生成假点位。更新地址后仍须单独核验坐标；精确化应取得门店确认或地图服务的可信结果，并记录来源、核验日期及坐标系。OpenStreetMap 使用 WGS84，不能直接混用 GCJ-02/BD-09 精确坐标。

## 实现与维护

- `web/src/components/boards/CityMap.vue`：全国/城市下钻、经营数据、内嵌地图切换、详情与全屏。
- `web/src/components/boards/StoreStreetMap.vue`：Leaflet 街道底图、标记、视野适配、加载失败提示、资源释放。
- `web/src/data/geoMeta.ts`：城市映射与既有概位。修复苏州、杭州、郑州等“州”字城市识别；保留真实远端门店，不按距离裁掉点位。
- `web/scripts/map-location.test.mjs`：城市、32 家门店、定位精度、原位地图回归检查。

在 web 目录执行 `npm run test:map`（Node.js 22.18+）及 `npm run build`。

## 地图服务

使用 [Leaflet 1.9.4](https://leafletjs.com/reference.html) 和 [OpenStreetMap 标准瓦片](https://operations.osmfoundation.org/policies/tiles/)。保留可见署名，仅请求当前视野所需瓦片，使用浏览器正常缓存，不批量下载或预取。道路图需要网络；加载异常可重试或切换已打包的区域图。版权链接只用于地图署名，不是查看门店位置的必经步骤。

公共瓦片服务不提供可用性保证。大规模公开上线前应按服务政策评估容量、稳定性及当地地图合规要求，并选用适当的服务商；本次没有申请账号、购买服务或上传门店经营数据。
