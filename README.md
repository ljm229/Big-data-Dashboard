# 淘宝闪购经营数据看板

淘宝闪购经营数据看板是面向公司内部运营人员和开发人员的经营分析系统，用于查看门店经营、流量、盈亏、运营质量、商品周期和风险等数据。

项目通过自动化脚本从翱象、淘宝闪购后台等数据源获取业务数据，经过校验后写入公司 MySQL 数据库 `taobian`，再生成前端 JSON 快照，最终由 Vue 前端进行可视化展示。

## 项目背景

日常运营数据来源较多，人工下载、整理和分析效率较低，也容易出现数据重复、日期错误和指标口径不一致等问题。

本项目用于统一以下流程：

- 自动采集淘宝闪购及翱象业务数据
- 对导入数据进行日期、粒度和完整性校验
- 将业务数据写入公司 MySQL 数据库
- 生成前端使用的数据快照
- 通过经营看板展示核心指标和分析结果
- 支持门店、城市、渠道、商品和业务日期等维度分析

## 核心功能

### 经营分析

- 门店经营概况
- 销售额、订单量、客单价等核心指标
- 城市和门店排名
- 经营趋势分析
- 新店开业和门店表现跟踪

### 流量分析

- 曝光、访问、点击和转化分析
- 流量趋势监控
- 门店流量健康度分析
- 城市及渠道流量对比

### 利润和成本分析

- 销售收入和利润分析
- 成本构成分析
- 订单毛利分析
- 利润趋势和门店利润对比

### 运营质量和风险分析

- 运营质量检查
- 风险门店识别
- 异常数据提示
- 门店经营诊断

### 数据管理

- 业务数据自动抓取
- Excel 数据导入
- MySQL 幂等写入
- 数据刷新状态记录
- MySQL 数据生成前端 JSON 快照
